= Spring Data DynamoDB
:project-url: https://github.com/Not-Your-Average-Dev/spring-data-dynamodb
:toc: macro

DynamoDB support for Spring Data.

This independent community project is at repository bootstrap stage,
`0.1.0-SNAPSHOT`. The build and module boundaries are in place; repository APIs,
mapping, queries, and Spring Boot auto-configuration are not implemented yet.
No release is advertised as available on Maven Central.

== Requirements and build

Use JDK 17 or later. The Maven Wrapper downloads Maven 3.9.16 and validates its
SHA-256 checksum; a separate Maven installation is unnecessary.

[source,shell]
----
./mvnw verify
----

On Windows, use `mvnw.cmd verify`. The compiler targets Java 17 even when the
build runs on a newer JDK. Empty-JAR and no-tests messages are expected during
bootstrap.

The parent imports Spring Boot `4.0.8` and AWS SDK for Java v2 `2.54.17` BOMs.
Spring Data Commons is managed by the Boot BOM. CI verifies Java 17 with the
default baseline and the `spring-boot.compatibility.version` from the parent POM.
To run that compatibility check locally:

[source,shell]
----
./mvnw -Dspring-boot.version=4.1.1 verify
----

== Planned consumer coordinates

These examples describe the intended `0.1.0` release coordinates. They will become
usable after that release is published.

=== Core-only applications

[source,xml]
----
<dependency>
    <groupId>dev.notyouraverage</groupId>
    <artifactId>spring-data-dynamodb</artifactId>
    <version>0.1.0</version>
</dependency>
----

The core library is independent of Spring Boot.

=== Spring Boot applications

[source,xml]
----
<dependency>
    <groupId>dev.notyouraverage</groupId>
    <artifactId>spring-data-dynamodb-spring-boot-starter</artifactId>
    <version>0.1.0</version>
</dependency>
----

The starter aggregates the Boot integration, the core Boot starter, and the AWS
Apache HTTP client at runtime. It contains no Java classes.

== Repository guide

The Maven reactor has four modules: core, Spring Boot integration, dependency
starter, and distribution. The parent manages their shared version and build.
Documentation lives under link:src/main/antora/[src/main/antora]. Start with the
link:src/main/antora/modules/ROOT/pages/architecture.adoc[module and namespace guide]
and the link:src/main/antora/modules/ROOT/pages/releases.adoc[release checklist].
The Antora site and release archive pipelines will be introduced later in the
distribution module.

link:SECURITY.adoc[security reporting], and link:CHANGELOG.adoc[the changelog].
