= Spring Data DynamoDB
:project-url: https://github.com/Not-Your-Average-Dev/spring-data-dynamodb

DynamoDB support for Spring Data, with a Spring Boot starter and a core library
for applications that do not use Spring Boot.

The project is in early development at `0.0.1-SNAPSHOT`. The current version
contains the project scaffold; client auto-configuration, mapping and repository
support are still under development. No release is available on Maven Central yet.

== Requirements

* Java 17 or later.
* Spring Boot 4.0.x for applications using the starter.

The link:pom.xml[parent POM] manages the Spring Boot and AWS SDK for Java v2
versions. The core library does not require Spring Boot.

== Using the library

The following coordinates are planned for the first `0.0.1` release. They are
provided for reference and cannot be used from Maven Central until publication.

=== Spring Boot applications

Add the starter to your application:

[source,xml]
----
<dependency>
    <groupId>dev.notyouraverage</groupId>
    <artifactId>spring-data-dynamodb-spring-boot-starter</artifactId>
    <version>0.0.1</version>
</dependency>
----

The starter includes the Spring Boot integration and the AWS SDK's Apache HTTP
client. Configuration will use the `spring.data.dynamodb` namespace. Configuration
examples will be documented here as the corresponding features become available.

=== Applications without Spring Boot

Use the core library directly:

[source,xml]
----
<dependency>
    <groupId>dev.notyouraverage</groupId>
    <artifactId>spring-data-dynamodb</artifactId>
    <version>0.0.1</version>
</dependency>
----

The core library depends on Spring Data Commons and the AWS SDK for Java v2,
including the DynamoDB Enhanced Client.

== Building from source

Clone the repository and build with the included Maven Wrapper:

[source,shell]
----
git clone https://github.com/Not-Your-Average-Dev/spring-data-dynamodb.git
cd spring-data-dynamodb
./mvnw verify
----

On Windows, use `mvnw.cmd verify`. A separate Maven installation is unnecessary.
The first build requires network access to download Maven and dependencies.
Empty-JAR and no-tests messages are expected while the project contains only the
scaffold.
